# 2048 应用图标 · 设计 Brief

- 任务：为 2048 游戏（web 原型 / Windows WebView2 外壳 / 安卓 WebView 外壳 三端）设计统一应用图标
- 核心对象：无实体商品；本任务核心对象是「2048 游戏」本身
- 画布 Workspace：cws_62069030561775106
- 生产轨道：pure-image（单一 App 图标，位图最终交付）

## 交付与规格

- 主图 1024×1024，1:1 正方形，PNG
- 由主图确定性缩放派生：Windows `.ico`（16/24/32/48/64/128/256），安卓 mipmap（48/72/96/144/192），网页 favicon 32/16
- 不重新生图派生子尺寸，只做等比缩放

## 视觉继承（与现有 UI 完全同源）

来源：`web/assets/css/style.css` 的 `:root`

- 墨色描边 `#4A3B32`，粗描边 + 实心偏移投影（原型为 `0 7px 0` 无模糊硬影）
- 奶油底 `#FFF8F0`，棋盘面 `#F3E5D6`
- 马卡龙色：粉 `#FF9EC4` / 粉深 `#FF7AA8`、薄荷 `#7ED9A0`、黄 `#FFE066` / 金 `#FFC93C`、蓝 `#8FC9FF`、薰衣草 `#C4A8FF`、橙 `#FFB067`
- 圆角：方块显著圆角，近似 12%–14% 边长的圆角半径
- 数字气质：粗重圆润、笔画饱满、居中对齐（对应原型 `font-weight: 900` 与 Q 版马卡龙方块）

## 颜色角色（≤4，符合 Logo 计色上限）

1. 主色：粉 `#FF9EC4`
2. 墨色：`#4A3B32`（描边与数字）
3. 表面色：奶油白 `#FFF8F0`
4. 强调色：黄 `#FFE066`（仅局部小面积）

不加渐变。不使用多层彩边、发光、软阴影、3D 立体、拟物质感。

## 构图

- 正方形画布中央，一个圆角方块主体，占画面约 72%–78% 边长，水平垂直居中，四周留出充足安全区
- 方块内单行横排数字「2048」，深棕墨色，占方块内部可用宽约 82%，垂直居中
- 角度正面正视，无透视、无旋转
- 方块带深棕粗描边与向下方的实心偏移投影（硬边、无模糊），形成原型的「贴纸感」
- 若需第二视觉元素，只允许一个：在方块外侧一角放一枚小尺寸方形色块或小星星，面积不超过主方块 10%，且不得遮挡数字

## 可见文字

唯一文字：「2048」。四个字符逐字准确，不添加任何其他字符、字母、标点、副标、域名、年份、TM/R、口号。

## 背景

纯奶油白 `#FFF8F0` 均匀平面底，不含纸张、墙面、摄影、渐变或场景。图标本体即方块，底色属于载体而非 Logo 图形。

## 禁止项

- 不出现在场景、桌面、手机、设备 Mockup
- 不添加无关吉祥物、角色、表情包、插画细节
- 不使用渐变、软阴影、发光、玻璃、金属、黏土质感
- 不使用细线、碎细节、微孔；48px 缩略下必须仍能读出「2048」与方块轮廓
- 不复刻任何现成 Logo 或图库图标，不使用默认字体加外框冒充定制
- 不生成二维码、水印、伪注册标、条码式细节

## 小尺寸验收

缩到 48px：方块轮廓与「2048」仍可辨；描边不吞字腔；投影不糊成一团。
